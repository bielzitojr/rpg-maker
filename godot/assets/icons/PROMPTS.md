# Ícones do hub

Gerados com a ferramenta integrada image_gen, sem CLI. Os PNGs finais estão nesta pasta. A imagem enviada pelo usuário orientou a escolha do dourado sobre fundo escuro; são novas ilustrações, não recortes da referência.

## character.png

Use case: stylized-concept. Create a single production-ready fantasy RPG HUD icon: a front-facing adventurer bust wearing a hood, face in shadow. Square image, centered silhouette with ample padding, antique gold engraved metal, warm amber highlights, restrained hand-painted game UI style, legible at 40px. Transparent background, no frame, no text, no letters, no watermark. Match a dark charcoal and muted gold RPG interface.
